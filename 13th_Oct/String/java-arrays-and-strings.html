Part 1: Arrays

1. Array basics

An array is a fixed-size, ordered collection of elements of the same type, stored in contiguous memory and accessed by index starting at 0. The size is set when the array is created and can never change.

int[] marks;                          // declaration (preferred style)
marks = new int[5];                   // creation: 5 slots, all 0
int[] ages = {18, 19, 20};            // declaration + initialisation
String[] names = new String[]{"Asha", "Ravi"};

System.out.println(ages.length);      // 3  (a field, not a method: no parentheses)

Every slot gets a default value when you create an array with new:

Element typeDefault
byte, short, int, long0
float, double0.0
char'\u0000' (the null character)
booleanfalse
any object, including Stringnull

2. Access, iteration and exceptions

int[] a = {10, 20, 30, 40};

for (int i = 0; i < a.length; i++)   // index loop: use when you need the position
    System.out.print(a[i] + " ");

for (int x : a)                       // for-each: read-only view of each value
    System.out.print(x + " ");

a[4] = 50;     // ArrayIndexOutOfBoundsException (valid indexes: 0 to 3)
int[] n = new int[-1];   // NegativeArraySizeException
int[] z = null;
z[0] = 1;      // NullPointerException
Common bug
Writing i <= a.length in a loop reads one slot past the end. The last valid index is always length - 1. Also, assigning to the for-each variable does not change the array.

Classic example, finding the largest element:

int max = a[0];
for (int i = 1; i < a.length; i++)
    if (a[i] > max) max = a[i];

3. Two-dimensional and jagged arrays

Java has no true matrix type. A 2D array is an array of arrays, so each row can have a different length (a jagged array).

int[][] grid = new int[3][4];                 // 3 rows, 4 columns
int[][] m = { {1, 2, 3}, {4, 5, 6} };
System.out.println(m[1][2]);                  // 6
System.out.println(m.length + " " + m[0].length);   // 2 3  (rows, columns)

int[][] tri = new int[3][];                   // only rows allocated
for (int i = 0; i < 3; i++) tri[i] = new int[i + 1];   // lengths 1, 2, 3

for (int[] row : m) {                         // print a matrix
    for (int v : row) System.out.print(v + " ");
    System.out.println();
}

4. Arrays are objects: references, copying and comparing

An array variable holds a reference to the array object on the heap. Assigning it copies the reference, not the data.

int[] a = {1, 2, 3};
int[] b = a;            // b points to the SAME array
b[0] = 99;
System.out.println(a[0]);          // 99

int[] c = a.clone();               // new array, same values (shallow copy)
int[] d = Arrays.copyOf(a, 5);     // new array of length 5: {99,2,3,0,0}

System.out.println(a == c);                  // false: different objects
System.out.println(a.equals(c));             // false: equals is NOT overridden for arrays
System.out.println(Arrays.equals(a, c));     // true: compares contents

static void change(int[] arr) { arr[0] = -1; }   // caller sees this change
static void reassign(int[] arr) { arr = new int[]{7}; }   // caller does NOT see this
Interview point
Java is always pass-by-value. For arrays the value passed is the reference, so a method can modify the elements but cannot make the caller's variable point to a new array. Also note clone() on a 2D array copies only the outer array; the rows are shared.

5. The Arrays utility class

import java.util.Arrays;

int[] a = {5, 2, 9, 1};
Arrays.sort(a);                              // {1, 2, 5, 9}, in place
int pos = Arrays.binarySearch(a, 5);         // 2 (array must be sorted first)
Arrays.fill(a, 0);                           // {0, 0, 0, 0}
System.out.println(Arrays.toString(a));      // "[0, 0, 0, 0]"  (a bare println(a) prints [I@1b6d3586)

int[][] m = {{1, 2}, {3, 4}};
System.out.println(Arrays.deepToString(m));  // "[[1, 2], [3, 4]]"

int[] part = Arrays.copyOfRange(a, 1, 3);    // indexes 1 and 2
Integer[] boxed = {3, 1, 2};
Arrays.sort(boxed, Collections.reverseOrder());   // descending needs object arrays
List<Integer> list = Arrays.asList(boxed);        // fixed-size list backed by the array

Arrays.sort on primitives uses dual-pivot quicksort; on objects it uses a stable merge sort variant (TimSort).

6. Varargs, and arrays vs ArrayList

Varargs let a method accept any number of arguments; inside, the parameter is an ordinary array. It must be the last parameter.

static int sum(int... nums) {          // sum(), sum(1), sum(1, 2, 3) all work
    int total = 0;
    for (int n : nums) total += n;
    return total;
}

Practice: Arrays

  1. What does this print?
    int[] a = new int[3];
String[] s = new String[2];
System.out.println(a[1] + " " + s[0]);
    Answer0 null. Arrays are filled with default values: 0 for int, null for objects.
  2. What is wrong with for (int i = 0; i <= arr.length; i++) sum += arr[i];?
    AnswerOn the last iteration i == arr.length, which throws ArrayIndexOutOfBoundsException. Use i < arr.length.
  3. Write code to reverse an array in place.
    Answer
    for (int i = 0, j = a.length - 1; i < j; i++, j--) {
    int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
}
  4. Why does System.out.println(new int[]{1,2}) print something like [I@15db9742?
    AnswerArrays do not override toString(), so you get the type code, @ and a hash. Use Arrays.toString(arr).
  5. Given int[] a = {1,2,3}; int[] b = a; b[0] = 9;, what is a[0]? How do you get an independent copy?
    Answer9, because both variables refer to one array. Use a.clone() or Arrays.copyOf(a, a.length).
  6. Interview: find the second largest element in one pass.
    Answer
    int first = Integer.MIN_VALUE, second = Integer.MIN_VALUE;
for (int x : a) {
    if (x > first) { second = first; first = x; }
    else if (x > second && x != first) second = x;
}
    Time O(n), extra space O(1).

Part 2: Strings

1. String basics

A String is an object that holds a sequence of characters (stored as UTF-16 code units). It is a class, not a primitive, and the most-used class in Java. Strings are immutable: no method changes an existing string; each one returns a new string.

String a = "hello";                    // literal
String b = new String("hello");        // explicit object
char[] chars = {'h', 'i'};
String c = new String(chars);          // from a char array

String s = "java";
s.toUpperCase();                       // returns "JAVA" but s is unchanged
s = s.toUpperCase();                   // reassign to keep the result
s.concat(" rocks");                    // result thrown away unless assigned

Why immutable? It makes strings safe to share between threads, safe as HashMap keys (the hash never changes), and safe for security-sensitive values like file paths. It also allows the string pool.

2. The string constant pool

Literals are stored in a special area called the string pool. If the same literal appears twice, Java reuses one object. new String(...) always creates a separate object on the heap.

String a = "hello";
String b = "hello";
String c = new String("hello");

System.out.println(a == b);            // true  (same pooled object)
System.out.println(a == c);            // false (c is a different object)
System.out.println(a.equals(c));       // true  (same characters)
System.out.println(a == c.intern());   // true  (intern() returns the pooled copy)

String x = "hel" + "lo";               // compile-time constant, so pooled
String y = "hel";
String z = y + "lo";                   // computed at runtime, so a new object
System.out.println(a == x);            // true
System.out.println(a == z);            // false

new String("hello") creates one heap object (plus the pooled literal if it was not already there), so it is wasteful. Prefer plain literals.

3. Comparing strings

MethodWhat it does
==Compares references (same object?). Almost never what you want for strings.
equals(s)Compares the characters, case-sensitive.
equalsIgnoreCase(s)Compares characters ignoring case.
compareTo(s)Dictionary order. Returns negative, 0 or positive (difference of the first differing characters, or of the lengths).
"apple".compareTo("banana");     // negative ('a' - 'b' = -1)
"b".compareTo("a");              // 1
"abc".compareTo("abcde");        // -2  (length difference)
"Java".equalsIgnoreCase("JAVA"); // true

String input = null;
"admin".equals(input);           // false, safe
input.equals("admin");           // NullPointerException: put the literal on the left

4. Important String methods

String s = "  Hello, World  ";

s.length();                         // 16
s.trim();                           // "Hello, World"  (strip() also handles Unicode spaces)
String t = s.trim();
t.charAt(0);                        // 'H'   (index must be 0 to length-1, else StringIndexOutOfBoundsException)
t.indexOf('o');                     // 4
t.lastIndexOf("o");                 // 8
t.indexOf("xyz");                   // -1  (not found)
t.substring(7);                     // "World"
t.substring(0, 5);                  // "Hello"  (end index is exclusive)
t.contains("World");                // true
t.startsWith("He");                 // true
t.endsWith("d");                    // true
t.replace('l', 'L');                // "HeLLo, WorLd"
t.replace("World", "Java");         // "Hello, Java"
t.toLowerCase();                    // "hello, world"
t.isEmpty();                        // false (length == 0)
"   ".isBlank();                    // true  (Java 11+)
"ab".repeat(3);                     // "ababab" (Java 11+)

String[] parts = "a,b,,c".split(",");        // ["a", "b", "", "c"]
String joined = String.join("-", "x", "y");  // "x-y"
char[] arr = t.toCharArray();                // to modify characters, then new String(arr)
Common bug
split takes a regular expression. To split on a dot or pipe, escape it: s.split("\\.") and s.split("\\|"). Trailing empty strings are dropped.

5. StringBuilder and StringBuffer

Because each + on strings makes a new object, building a string in a loop is slow. StringBuilder is a mutable character buffer that changes in place.

StringBuilder sb = new StringBuilder();
for (int i = 0; i < 5; i++) sb.append(i).append(',');   // fast: one buffer
sb.append("end");
sb.insert(0, "[");            // [0,1,2,3,4,end
sb.reverse();
sb.setCharAt(0, 'X');
sb.deleteCharAt(sb.length() - 1);
String result = sb.toString();   // convert back when finished

String bad = "";
for (int i = 0; i < 10000; i++) bad += i;   // creates thousands of temporary strings
StringStringBuilderStringBuffer
MutableNoYesYes
Thread-safeYes (immutable)NoYes (synchronized)
Speed for editsSlowFastestSlower than StringBuilder
equals()Compares contentNot overridden: compares references

Rule of thumb: use String for fixed text, StringBuilder for building text in loops, and StringBuffer only when several threads share one buffer.

6. Conversions, formatting and text blocks

int n = Integer.parseInt("42");          // String to int
String s1 = String.valueOf(42);          // int to String
String s2 = 42 + "";                     // also works, less clear
double d = Double.parseDouble("3.5");

String f = String.format("%s scored %d (%.2f%%)", "Asha", 87, 87.456);
// "Asha scored 87 (87.46%)"   %s string, %d integer, %f decimal, %n newline

String block = """
    Roll: 101
    Name: Asha
    """;                                 // text block (Java 15+), keeps line breaks

// Palindrome check
static boolean isPalindrome(String s) {
    return new StringBuilder(s).reverse().toString().equals(s);
}

// Count characters
int[] freq = new int[26];
for (char ch : "hello".toCharArray()) freq[ch - 'a']++;   // freq['l' - 'a'] == 2

Strings also work in switch (compared with equals), and chars can be used in arithmetic: 'a' + 1 is the int 98, while (char)('a' + 1) is 'b'.

  1. What is printed?
    String a = "Java", b = "Java", c = new String("Java");
System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));
    Answertrue false true. Literals share one pooled object; new makes a separate object; equals compares content.
  2. What does this print?
    String s = "hello";
s.toUpperCase();
s.concat(" world");
System.out.println(s);
    Answerhello. Strings are immutable and the returned values were discarded.
  3. What is "Programming".substring(3, 7)?
    Answer"gram": characters at indexes 3, 4, 5, 6 (end is exclusive).
  4. How many objects does String s = new String("abc"); create, at most?
    AnswerTwo: the pooled literal "abc" (if not already there) and the heap object created by new.
  5. Write a method to count vowels in a string.
    Answer
    static int vowels(String s) {
    int n = 0;
    for (char c : s.toLowerCase().toCharArray())
        if ("aeiou".indexOf(c) != -1) n++;
    return n;
}
  6. Check whether two strings are anagrams.
    Answer
    static boolean anagram(String a, String b) {
    char[] x = a.toCharArray(), y = b.toCharArray();
    Arrays.sort(x); Arrays.sort(y);
    return Arrays.equals(x, y);
}
    Sorting costs O(n log n); a 26-slot frequency array does it in O(n).
  7. Interview: why is String immutable, and when would you use StringBuilder?
    AnswerImmutability gives thread safety, stable hash codes for map keys, security, and enables the string pool. Use StringBuilder when you modify or append repeatedly, especially in loops, to avoid creating many temporary strings.

Quick summary

  • Arrays are fixed-size, zero-indexed and hold one type. They are objects, so variables hold references; use Arrays.toString, Arrays.equals and clone/copyOf for printing, comparing and copying.
  • 2D arrays are arrays of arrays and can be jagged. length is a field for arrays and a method for strings.
  • Strings are immutable. Compare content with equals, never ==; literals live in the string pool.
  • Use StringBuilder to build strings in loops; remember that split takes a regex.
