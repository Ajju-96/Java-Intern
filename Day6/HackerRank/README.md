# Java Practice Questions

This folder contains three standalone Java solutions.

## 1. Employee Salary Calculator
**Concepts:** Inheritance, method overriding, `super`, formatted output.

The regular employee receives a 10% bonus and the manager receives a 20% bonus.

Sample input:
```text
Rahul
20000
Priya
30000
```

Sample output:
```text
Employee: Rahul, Total Salary: 22000.00
Manager: Priya, Total Salary: 36000.00
```

Run:
```bash
javac EmployeeSalaryCalculator.java
java EmployeeSalaryCalculator
```

## 2. Second-Largest Distinct Number
**Concepts:** Arrays, loops, comparisons, distinct values.

Prints the second-largest distinct element. If there are fewer than two distinct values, prints `Not Possible`.

Sample input:
```text
6
10 20 5 20 8 15
```

Sample output:
```text
15
```

Run:
```bash
javac SecondLargestDistinctNumber.java
java SecondLargestDistinctNumber
```

## 3. Special Number
**Concepts:** Modulo, integer division, arrays, loops, factorials.

A number is special if the sum of the factorials of its digits equals the number itself.

Sample input:
```text
145
```

Sample output:
```text
Special Number
```

Run:
```bash
javac SpecialNumber.java
java SpecialNumber
```
